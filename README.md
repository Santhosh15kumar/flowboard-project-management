# FlowBoard - Project Management Application

A full-stack project management application with Kanban task management.

## Tech Stack

### Frontend

- Angular 22
- TypeScript
- SCSS
- Angular Signals and RxJS

### Backend

- Node.js
- Express.js
- TypeScript
- REST APIs

### Database

- MySQL 8

## Planned Features

- User registration and authentication
- Project management
- Kanban task management
- Task assignment and priorities
- Task search and filtering
- Dashboard statistics

## Project Structure

- frontend/ - Angular application
- backend/ - Node.js and Express API
- database/ - Database scripts
- docs/ - Project documentation
